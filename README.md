# Fotbal – nejpopulárnější sport na světě

Fotbal je jeden z nejpopulárnějších sportů na světě. Hrají ho miliony lidí po celém světě.

## 1. Základní pravidla fotbalu

Fotbal hrají proti sobě dva týmy. Každý tým má na hřišti 11 hráčů.

### 1.1 Délka zápasu

- Zápas trvá 90 minut.
- Hraje se na dva poločasy.
- Každý poločas trvá 45 minut.

### 1.2 Fotbalové pozice

1. Brankář
2. Obránce
3. Záložník
4. Útočník
